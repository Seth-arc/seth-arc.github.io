06 / Learning systems R&D

Neckbeard

Teludens Lab · 2026

Open source / agent skill

Built behind the curtain at Teludens Lab, my experimental lab: an AI agent skill that reads a software repository and writes the onboarding and learning documentation people need to use it.

What I built

The instructional architecture, evidence model and implementation: a required core plus eight optional components for end users, administrators, developers, practice, maintenance, media, support and release training; an organisation profile for house style, approved tools and reviewers; and a checksum-verified installer for Codex, Claude and Cursor.

Evidence of delivery

Tutorials give the real commands, what learners should see at each step and how to recover when something goes wrong. A verification record separates what was run from what was only read in the code, and Neckbeard makes no claim about learning effectiveness without learner evidence. 23 automated tests pass.
